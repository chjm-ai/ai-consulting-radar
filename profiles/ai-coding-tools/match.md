# AI编程工具

当一条内容涉及 AI 辅助编程、代码生成、开发者工具链中的 AI 集成时，使用此配置。

包括：AI 代码助手（Cursor、Copilot、Claude Code、Windsurf、Codex 等）的发布、更新、对比评测；AI Agent 编程框架（LangChain、CrewAI、AutoGen 等）；AI 驱动的测试、部署、运维工具；代码大模型（CodeLlama、DeepSeek-Coder、Qwen-Coder 等）的发布和评测；AI 编程的工作流方法论和最佳实践；开发者使用 AI 编程的真实体验和效率数据。

不包括：通用大模型发布（除非专门针对编程场景）；纯学术论文无工具化落地；通用 IDE 功能更新与 AI 无关的部分；AI 在非编程领域的应用（归其他 profile）。
